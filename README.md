「연구행정 업무 효율성 제고를 위한 생성형 AI 활용 교육」(2026. 9. 4., 오송보건의료행정타운) 보충자료입니다.

## 내용

1. 한글 파일(HWP·HWPX)은 어떻게 넣는가
2. 자료 형태별 대응
3. AI 도구, 네 갈래 — 대화형 / 문서 기반 / 에이전트 / 업무 자동화
4. 무료로 어디까지 되는가
5. 업무별로 무엇을 쓸까
6. 복사해서 쓰는 프롬프트 12개
7. 결과 검증 체크리스트와 자료 입력 기준
8. 사전설문 질문에 대한 짧은 답
